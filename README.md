# 수학 실전 모의고사 분석 보고서

실전 모의고사 피드백을 웹에서 바로 작성하고, 정리된 보고서 형태로 저장할 수 있는 정적 웹앱입니다.

브라우저 안에서 바로 문서를 수정하는 방식으로 동작하며, 별도의 백엔드 없이 `HTML`, `CSS`, `JavaScript`만으로 구성되어 있습니다.

## 주요 기능

- 보고서 양식 안에서 직접 내용 편집
- 회독 추가 / 삭제
- 문항 행 추가 / 삭제
- `Enter` 입력으로 다음 문항 칸으로 이동하며 새 행 자동 생성
- 하단 `느낀 점`, `FEEDBACK` 영역 편집
- 작성 내용 자동 저장
- 보고서를 이미지(`PNG`)로 다운로드

## 프로젝트 구조

```text
math-feedback-app/
├─ index.html
├─ styles.css
├─ app.js
└─ README.md
```

## 실행 방법

이 프로젝트는 정적 사이트이므로 별도 설치가 필요하지 않습니다.

1. `index.html`을 브라우저에서 열기
2. 또는 정적 서버로 폴더를 열어서 사용

예시:

```bash
# Python이 있는 경우
python -m http.server 8000
```

그 뒤 브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

## 사용 방법

1. 문서 제목, 점수, 등급컷을 클릭해서 직접 입력합니다.
2. 각 회독 영역에서 문항 번호와 피드백을 입력합니다.
3. 회독은 상단 `+ 회독`, `- 회독` 버튼으로 조절합니다.
4. 각 회독 오른쪽의 `+` 버튼으로 문항 행을 추가합니다.
5. 상단 저장 버튼으로 현재 보고서를 이미지로 다운로드합니다.

## 저장 방식

작성 내용은 브라우저의 `localStorage`에 자동 저장됩니다.

- 같은 브라우저에서 다시 열면 이전 내용이 남아 있습니다.
- 다른 기기나 다른 브라우저로는 자동 동기화되지 않습니다.

## 배포 방법

가장 간단한 방법은 `GitHub Pages` 배포입니다.

1. GitHub에 새 저장소 생성
2. `index.html`, `styles.css`, `app.js`, `README.md` 업로드
3. 저장소의 `Settings > Pages`로 이동
4. `Deploy from a branch` 선택
5. `main` 브랜치의 `/ (root)` 폴더 배포로 설정

배포가 완료되면 아래 형태의 주소로 접속할 수 있습니다.

```text
https://사용자이름.github.io/저장소이름/
```
